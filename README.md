# Fluent（暂定名）

在**任意程序**里选中文字，点一下，弹出小面板帮你处理英文。不用快捷键。macOS + Windows，一套代码（Tauri 2）。

完整规格见 [SPEC.md](SPEC.md)。当前进度：**M0–M3 完成**：翻译、总结、改写、回复、朗读，以及替换原文。

## 用法

在任意程序里用鼠标选中文字（在文字上拖选或双击；按下时光标须是 I 形文字光标，在桌面、标题栏上拖动不会触发），光标正下方会冒出一个长条按钮（水平居中对齐光标）：**翻译 | 总结 | 改写 | 回复 | 朗读**，点哪个就直接打开哪个功能。长条 5 秒后自动消失（鼠标停在上面时不消失），点别处、右键、滚动也会消失。

- **mac** 第一次运行会请求「辅助功能」权限（系统设置 → 隐私与安全性 → 辅助功能 → 打开 Fluent），开了之后按钮才会出现。备用入口：选中文字 → 右键 → 服务 → **用 Fluent 翻译**（不需要权限）。
- **Windows** 不需要额外权限。

光标下方会弹出面板，打开你点的那个功能；顶部有五个功能页，也可以按数字键 1–5 切换：

| 键 | 功能 | 说明 |
|---|---|---|
| 1 | 翻译 | 英文 → 中文，中文 → 英文；行话缩写附中文解释 |
| 2 | 总结 | 中文：一句话主旨 + 要点 + 要我做的（含截止时间） |
| 3 | 改写 | 把你的草稿改成地道英文；语气可选正式 / 中性 / 友好 / 简洁；可勾选「显示改了什么」 |
| 4 | 回复 | 选中收到的邮件 / 消息，用中文写想怎么回（可留空），选立场和语气，点「生成回复」 |
| 5 | 朗读 | 自动读一遍；可暂停、调语速（0.75× / 1× / 1.25×）、选美音 / 英音；单词或短语还会给音标 |

- ⌘C / Ctrl+C 复制结果，Esc 关闭。
- 改写和回复的结果可以直接在面板里修改。点「替换原文」（⌘↵ / Ctrl+Enter），Fluent 会切回原程序，用结果替换你选中的文字。它**不会按回车、不会替你发送**。
- 朗读默认用系统语音（免费）。在设置里可以换成云端语音（OpenAI / Gemini，更自然，按量付费）。

App 常驻菜单栏（mac）或系统托盘（Windows），从那里打开「设置」填 API Key。

## 隐私

- 只在你点了划词按钮（或 mac 右键菜单项）之后才读取选中的文字，不保存任何内容。
- 划词检测只看鼠标动作（按下、松开、坐标），不读文字、不监听键盘。点了按钮后用模拟复制（⌘C / Ctrl+C）取文字，之后还原你原来的剪贴板。
- API Key 存在系统凭据库（mac 钥匙串 / Windows 凭据管理器），日志里不会出现 Key 和你的文本。
- Gemini 请用**付费 API Key**：免费 AI Studio Key 的数据可能被用于训练。
- 「替换原文」只粘贴，不发送；发不发由你决定。
- 公司内容发给第三方 AI 之前，请先确认公司政策。

## 开发

需要 Node 20+ 和 Rust（`rustup`）。

```bash
npm install
npm run tauri dev           # 开发模式（mac 的右键服务要用打包后的 .app 才会注册）
bash scripts/build-mac.sh   # 打包 build/Fluent.app 并用固定证书签名
cargo test --manifest-path src-tauri/Cargo.toml
```

只调界面时，可以单独跑 `npx vite`，然后在浏览器打开 `http://localhost:1420/#panel` 或 `#settings`。这时会自动加载假后端 `src/devMock.ts`。

**Windows**：GitHub Actions（`.github/workflows/build.yml`）会在 mac 和 Windows 上各打一次包，产物在 Actions 的 Artifacts 里下载（`.msi` / `.exe` / `.dmg`）。安装包未签名，Windows 会提示「未知发布者」，点「仍要运行」即可。

**在别的 Mac 上装 CI 打的 `.dmg`**：dmg 同时支持 Apple 芯片和 Intel，但只做了 ad-hoc 签名（没有苹果开发者证书、没有公证）。拖进「应用程序」后第一次打开会被拦，到 系统设置 → 隐私与安全性 底部点「仍要打开」。如果提示「已损坏」，在终端运行 `xattr -cr /Applications/Fluent.app` 再打开。每次更新版本后，辅助功能权限可能要在系统设置里关掉再打开一次。
